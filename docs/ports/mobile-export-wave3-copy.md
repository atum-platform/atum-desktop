# Wave 3 phone copy in the mobile design snapshot

The reviewed mobile snapshot gains the copy the iPhone's wave 2 and wave 3 work codes
against (backlog atum-mobile#50, "Design-export copy": EX-HC, EX-TL, EX-SC, EX-TS, EX-AS,
EX-ST, EX-ST-RM, EX-AC, EX-AC-PH, EX-MISC, EX-DT, EX-SUB), in all five locales (en, vi,
ja, zh, zh-Hant), so the phone can repin once (EX-REPIN). Owner ruling 6: phone copy comes
only from this export. Wording is desktop's own, as in wave 1
(`docs/ports/mobile-export-wave1-copy.md`):

- Keys the export already reads are promoted under their desktop key path.
- Where the export cannot read a table (i18n scopes other than `atum`, `common`,
  `timeline`, `dm`; files built from per-locale constants), the words are copied exactly into
  `mobileScreensCopy` in `apps/desktop/src/matrix/mobile-copy.ts`, with the source named
  beside them. The copies were generated by evaluating the desktop modules, not typed.
- Phone-only Settings words (EX-AC-PH) go in desktop's `phoneSettingsCopy` table
  (`apps/desktop/shared/matrix-settings-revamp-copy.ts`), the table made for words only the
  phone's Settings pages show.
