# Work Cowork S3 desktop relay

New Work drafts resolve the account's primary eligible assistant. Work
does not currently expose a separate assistant selector. Existing attached
threads keep their bound assistant when the account primary or chat room
changes.

After a confirmed relay outage or consent refusal, the bound Work thread can
continue locally through its native command receipt. A missing receipt is
bounded by the 45-second handoff deadline. Work and the relay share that
bound follow-up's command ID. An ambiguous new launch retains its draft for
retry. A busy receipt keeps the active Work run and the draft.

Focused connector tests exercise the selected provider, original assistant,
unreachable relay, explicit local fallback and busy receipts. Installed
assistant consent and transport were not exercised.
