# Atum Desktop — قابلِ مشاہدہ سورس کوڈ

اس ریپوزٹری میں Atum Desktop اور Hermes سے اخذ کردہ اس کے رن ٹائم کا شائع کردہ سورس کوڈ شامل ہے۔ Atum کے اپنے کوڈ کے تمام حقوق محفوظ ہیں۔ GitHub کی عوامی ریپوزٹری کی شرائط کے تحت دیکھنے اور فورک کرنے کے حقوق کے علاوہ کوئی اور لائسنس نہیں دیا جاتا۔ Hermes سے وراثت میں ملنے والا کوڈ MIT لائسنس کے تحت رہتا ہے، اور دیگر تیسرے فریق کے لائسنس اور انتساب بھی برقرار ہیں۔ [LICENSE](LICENSE)، [NOTICE](NOTICE) اور [THIRD-PARTY.json](THIRD-PARTY.json) پڑھیں۔

مقامی جانچ کے لیے `npm ci --ignore-scripts` اور پھر `npm run typecheck --workspace apps/desktop` چلائیں۔ انضمام کرنے والے اپنی تعیناتی کی ترتیب خود فراہم کریں؛ یہاں پروڈکشن کی ترتیب شامل نہیں ہے۔

Atum کی خرابیوں، تجاویز اور تعاون کے لیے [اسی ریپوزٹری کے مسائل](../../issues)، [پل ریکوئسٹس](../../pulls) اور [تعاون کی رہنمائی](CONTRIBUTING.md) استعمال کریں۔ حفاظتی مسائل نجی طور پر رپورٹ کریں؛ [SECURITY.md](SECURITY.md) دیکھیں۔

Atum، [Nous Research کے Hermes Agent](https://github.com/NousResearch/hermes-agent) سے اخذ کیا گیا ہے۔ اس کے لائسنس اور اصل انتساب برقرار رکھے گئے ہیں۔
