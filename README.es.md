# Atum Desktop — código fuente visible

Este repositorio contiene el código publicado de Atum Desktop y su entorno derivado de Hermes. El código propio de Atum tiene todos los derechos reservados: no se concede otra licencia que los derechos de visualización y bifurcación exigidos por las condiciones de GitHub para repositorios públicos. El código heredado de Hermes conserva su licencia MIT; las demás licencias y atribuciones también se mantienen. Consulta [LICENSE](LICENSE), [NOTICE](NOTICE) y [THIRD-PARTY.json](THIRD-PARTY.json).

Para las comprobaciones locales, ejecuta `npm ci --ignore-scripts` y `npm run typecheck --workspace apps/desktop`. Los integradores deben proporcionar su propia configuración de despliegue; este árbol no incluye configuración de producción.

Para errores y cambios de Atum, usa los [issues de este repositorio](../../issues) y la [guía de contribución](CONTRIBUTING.es.md). Los informes de seguridad son privados: consulta [SECURITY.es.md](SECURITY.es.md).
