# Ben — logo (6A)

Career & job hunting specialist. All-white wordmark on a blue squircle.

## Colour
- Blue: #4FA8D8
- Wordmark and dot: #FFFFFF

## Geometry (from the 168px master)
- Tile radius: 22.6% of tile width
- Wordmark: 600 weight, letter-spacing -0.055em, cap-centred
- Dot: 6.5% of tile width, gap 4.2%, sitting on the baseline of "n"

## Files
- ben-appicon-1024.png / -512.png — app icon
- ben-tile-256 / 128 / 64.png — in-app and list sizes
- ben-tile-32-nodot.png — below 40px the dot is dropped; the wordmark alone still reads
- ben-avatar-circle-1024.png — Zalo / Telegram avatar
- ben-wordmark-white-transparent.png — white wordmark, no tile
- ben-wordmark-blue-transparent.png — blue wordmark for light backgrounds

## Rules
- Never rotate or stretch the tile.
- Do not recolour the dot; it is the same white as the wordmark.
- Minimum tile size 30px; use the no-dot file below 40px.
